# OTDwx editorial style guide — v1

## House format (one standard post)

    #OTDwx: Month Day, Year:

    Injuries: [only if reliably verified]
    Fatalities: [only if reliably verified]

    [One short, specific factual account; meteorological insight when useful.]

    Source: [recognizable original source]

The statistics lines are **optional**. Do not force casualty counts into stories where other details are more interesting, and do not guess numbers. Multiple sources can be credited in the source label if space permits; store full research URLs in the event record. The screenshot supplied as inspiration demonstrates **formatting only**, not independently verified event facts.

- Absolute limit: 280 weighted X characters, including line breaks and source.
- Drafting target: at most 260 weighted characters where possible; drafts of 261–280 remain valid.
- A URL consumes approximately 23 weighted characters, so full source URLs generally belong in the editorial record, image attribution, or link when genuinely helpful.
- Use exactly one #OTDwx hashtag by default. No hashtag pileups, forced calls to action, or irrelevant emojis.
- Keep the date in the opening line; no need to start every narrative with "On this day..."
- Preserve standard English and the meteorological precision of the event. Avoid AI-sounding filler ("unleashed its fury", "historic event unfolded", "Mother Nature reminded us").
- Avoid implying a casualty number is associated with a single tornado if it actually refers to a multi-tornado outbreak.
- Distinguish preliminary estimates, updated tallies, and contemporary newspaper reports.
- Never claim the graphic is an original observation if it is a modern reconstruction.
- Never imply NOAA/NWS endorses this account.

## What earns publication

1. Exact event date and relevant location are established.
2. Core facts and figures are supported by cited primary/authoritative references.
3. Claim-by-claim review is complete; source attribution is meaningful and accurate.
4. Image/graphics provenance and rights have been checked; accessibility alt text is written.
5. It is readable as a standalone post and genuinely adds something beyond a generic anniversary note.
6. Character-limit preflight passes and a human explicitly approves the final words and media.

## Engagement without clickbait

Lead with the most distinctive *verified* detail. Use active verbs and specific geography. Vary emphasis between impact, atmospheric setup, an observation, a surprising record, or archival eyewitness context. Prefer simple descriptions to adjectives. Likes and reposts are an optimization metric, never a reason to inflate numbers or embellish dramatic details.

## Diversity guidance (editorial warnings, not automatic bans)

- Avoid repeating the previous post's region unless the anniversary warrants it.
- Warn if the prior two published posts have the same hazard category.
- Warn if the last two featured the same source agency.
- Flag repeated event IDs indefinitely; revisiting an event demands a substantially different documented angle.
- Rotate between disasters and less famous events, geography, time period, visual formats, and source institutions.
- Account for severe-impact sensitivity and avoid jokey language for fatal events.

## Status lifecycle

researching → drafted → fact_checked → approved → published

A rejected candidate uses rejected. Only manually approved content can ever be queued for an eventual publishing integration.
